# My Budget Tracker

## Week 2 Assignment

This project is a simple Budget Tracker created using HTML and CSS.

## Features

- Add Expense form
- Expense category dropdown
- Expense table
- Sample expense records
- Budgeting tip video
- Budget tracker logo
- How to use section
- Hover effects
- Advanced CSS selectors

## HTML Features Used

- Form
- Input fields
- Select dropdown
- Table
- Image
- YouTube iframe
- Details and summary elements

## CSS Features Used

- Descendant selector
- Direct child selector
- nth-child selector
- :hover
- :focus
- :not()
- Cursor pointer

## Purpose

The Budget Tracker allows users to record and view their expenses.
