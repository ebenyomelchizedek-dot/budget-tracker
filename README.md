# My Budget Tracker

## Project Description

My Budget Tracker is a simple web-based application designed to help users
organize and view their expenses in one place.

The project was developed as part of a web development assignment focusing
on CSS styling, typography, color palettes, form styling, table styling,
and the CSS Box Model.

## Technologies Used

- HTML5
- CSS3
- Google Fonts
- Responsive CSS

## Main Features

- Budget Tracker page heading
- Add Expense form
- Expense name input
- Amount input
- Expense category selection
- Date selection
- Expense table
- Responsive layout
- Budgeting tips section
- Embedded budgeting video

## Design

The project uses a consistent blue, white and slate color palette.

### Color Palette

- Primary Blue: #2563EB
- Dark Blue: #1E3A8A
- Background: #F1F5F9
- White: #FFFFFF
- Text: #1E293B
- Border: #CBD5E1

## Typography

The project uses two Google Fonts:

- Poppins for headings
- Inter for body text, labels, forms, buttons and tables

## CSS Box Model

The project demonstrates the CSS Box Model through:

- Margin
- Padding
- Borders
- Border-radius

The page heading, Add Expense form and Expense Table are presented as
separate visual cards.

## Responsive Design

A CSS media query is included to improve the layout on smaller screens
such as mobile phones and tablets.
